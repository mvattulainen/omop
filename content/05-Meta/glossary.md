# Glossary

| Term | Meaning in this vault |
|---|---|
| Clinical event | A source fact that something occurred, not merely that it was planned. |
| Crosswalk | Versioned association between a source key and a persistent target identifier. |
| Domain | OMOP table family selected by the standard concept's domain. |
| Imaginary EHR | The synthetic source system documented here. |
| Lineage | Evidence connecting target row, source row, code version, and run. |
| Normalization | Lossless standardization before OMOP-domain rules. |
| Reconciliation | Comparison of expected source cohorts/counts with target results. |
| Source concept | Vocabulary concept representing the original source code. |
| Standard concept | OMOP vocabulary concept used in analytical fields. |
| Visit reconstruction | Deterministic grouping of source encounter facts into visits and details. |

See also [[vault-conventions]] and [[omop-version-policy]].
